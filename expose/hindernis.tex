\chapter{Potenzielle Herausforderungen}
\begin{itemize}
	\item \textbf{Datenbankauswahl:} Die Wahl zwischen einer H2-In-Memory-Datenbank und einer produktionsnahen Datenbank beeinflusst die Aussagekraft der Integrationstests.
	\item \textbf{Testabdeckung:} Die Erreichung einer hohen Testabdeckung, insbesondere bei E2E-Tests, ist zeitintensiv.
	\item \textbf{Wartung der Tests:} Änderungen im Code erfordern eine regelmäßige Anpassung der Tests.
	\item \textbf{Testdaten:} Die Verwaltung konsistenter Testdaten ist komplex und erfordert eine sorgfältige Planung.
\end{itemize}
